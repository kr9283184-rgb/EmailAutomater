# Contributing

Thanks for contributing to Email Automator.

## Development

1. Create a branch from `main`.
2. Keep changes focused and preserve the application's safety limits.
3. Run `python -m unittest discover -s tests` before opening a pull request.
4. Update the README when configuration, deployment, or user-facing behavior changes.
5. Never commit SMTP credentials, generated `data/` files, or local secrets.

## Pull requests

Describe the change, how it was tested, and any environment-variable or deployment implications.
